SearXNG redesign

Search interface concepts

Five visual treatments using the same elephant search fixture. The search flow stays familiar so the comparison is mostly about spacing, surfaces, and density.

01

Restrained

Familiar flat

Closest to a conventional Google or DuckDuckGo results page. Mostly flat surfaces, comfortable spacing, and a quiet sidebar.

Open concept →
02

Soft

Grouped surfaces

A stronger Catppuccin treatment. Results share one rounded surface while the knowledge panel and related searches sit in matching panels.

Open concept →
03

Dense

Compact focus

Fits more information on screen with tighter rows, stronger metadata, and keyboard shortcuts. It stays calm rather than turning into a terminal.

Open concept →
04

Refined

Comfortable compact

Concept 03 without result numbering. It keeps the compact top bar and result structure, but uses larger type, more breathing room, subtle cards, and plain Catppuccin surfaces.

Open concept →
05

Reference-led

DDG results

Keeps the current top bar, then borrows DuckDuckGo's wide single-column results, horizontal answer card, inline media packs, and bottom related searches.
