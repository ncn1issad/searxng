How to implement JWT authentication and token refresh in FastAPI? Q&A

I am building a REST API with FastAPI and need to issue access tokens and refresh tokens. What is the standard dependency injection pattern using OAuth2PasswordBearer to verify expiration and return user models?

Accepted answer by tiangolo · 418 upvotes

Extract the bearer token with OAuth2PasswordBearer and decode it using PyJWT inside a dependency:

async def get_current_user(token: Annotated[str, Depends(oauth2_scheme)]):
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        username: str = payload.get("sub")
        if username is None:
            raise credentials_exception
    except InvalidTokenError:
        raise credentials_exception
    return get_user(db, username=username)

FastAPI OAuth2PasswordBearer returns 401 Unauthorized with valid token Q&A

My client sends Authorization: Bearer <token> to the /users/me endpoint, but FastAPI keeps throwing 401 Unauthorized before invoking my route dependency handler.

Accepted answer by encode_enthusiast · 156 upvotes

Verify that your tokenUrl parameter exactly matches your token endpoint route including or excluding trailing slashes. If you defined @app.post("/token/"), passing tokenUrl="token" triggers a redirect that drops the Authorization header.

Hardening Nginx reverse proxy headers for FastAPI OAuth2 and SSL termination Q&A

When terminating SSL at Nginx in front of a Uvicorn/FastAPI instance, OAuth2 redirect URLs generate http:// scheme instead of https://. Which headers must be configured?

Accepted answer by sysadmin_dan · 96 upvotes

Pass proxy_set_header X-Forwarded-Proto $scheme; and proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; in your Nginx location block, and start Uvicorn with the --proxy-headers flag.
