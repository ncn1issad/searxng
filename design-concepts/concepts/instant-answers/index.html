Production Implementation Blueprint

SearXNG Production Ready

This design concept operates directly on SearXNG's existing data structures without backend changes. Below are the required modifications to activate this visual language in production:

searx/templates/simple/elements/answers.html

Add semantic answer-card wrapper and clean ARIA region attributes.

<div id="answers" role="region" aria-label="Instant answers">
  {%- for answer in answers -%}
    <article class="answer-card">
      {%- include ("simple/" + (answer.template or "answer/legacy.html")) -%}
    </article>
  {%- endfor -%}
</div>

searx/templates/simple/answer/legacy.html

Structure the plain text answer into a hero metric and supporting formula.

<div class="card-header-strip">
  <span class="card-type-tag">Instant Answer</span>
  {%- if answer.url -%}
    <a href="{{ answer.url }}" class="card-source-link">
      {{ urlparse(answer.url).hostname }}
    </a>
  {%- endif -%}
</div>
<div class="answer-legacy-body">
  <div class="answer-primary-value">{{ answer.answer }}</div>
</div>

searx/templates/simple/answer/translations.html

Map translations to the hero row and transform <dl> children into pills and lists.

<details class="answer-translations">
  <summary>
    <div class="translation-summary-body">
      <div class="translation-primary-text">
        {{ answer.translations[0].text }}
      </div>
    </div>
    <div class="translation-expand-toggle">Details</div>
  </summary>
  <div class="translation-details-content">...</div>
</details>

client/simple/src/less/search-redesign.less

Add card envelope tokens, subtle 1px borders, and responsive grid layout.

#answers {
  grid-area: answers;
  display: flex;
  flex-direction: column;
  gap: 12px;
  max-width: 780px;

  .answer-card {
    border: 1px solid var(--ctp-surface-0);
    border-radius: 8px;
    background: var(--ctp-mantle);
  }
}
